# Eesa Organics

A modern, premium e-commerce website for **Eesa Organics** — natural and herbal products brand.

## Tech Stack

- React 18 (Vite)
- React Router
- Lucide React icons
- CSS3 (responsive, no framework)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build for Production

```bash
npm run build
npm run preview
```

## Configuration

Update business contact details in `src/config/contact.js`:

- WhatsApp number (international format, no + symbol)
- Phone, email, address
- Social media links

Update products in `src/data/products.js`.

Replace `/public/logo.svg` with your official Eesa Organics logo PNG if preferred.

## Features

- Responsive design (320px+)
- WhatsApp product ordering
- Product search and category filters
- Product detail pages with image gallery
- Contact form (sends enquiry via WhatsApp)
- SEO-friendly page titles and meta descriptions
